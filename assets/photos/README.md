# Photos

Max 3 photos per POI/attraction. Only use:
- Wikimedia Commons (check the license — CC0/CC-BY/CC-BY-SA only)
- Official tourism board sources
- Other properly licensed sources

Do not scrape Google Maps imagery. Convert to WebP/AVIF and keep files small — they're lazy-loaded, but still count toward what "Save for offline" downloads.

Filename convention: `<poi-id>-1.webp`, `<poi-id>-2.webp`, etc., matching the `id` in `data/attractions.json` / `data/places.json`. Nothing has been sourced yet.
